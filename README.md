# 📰 Mini Blog Website

A **responsive and minimal blog website** built using **HTML, CSS, and JavaScript**.  
This project demonstrates front-end web design, clean code, and interactive UI skills.

---

## 🚀 Features
- 🧱 Responsive layout for all devices  
- 🖋️ Simple blog post page  
- 📂 About page  
- 🎨 Clean, modern design  
- ⚡ Fast loading using pure HTML, CSS, and JS

---

## 🛠️ Technologies Used
- **HTML5** – Structure  
- **CSS3** – Styling  
- **JavaScript (ES6)** – Interactivity
